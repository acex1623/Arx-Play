# Arx-Play

A lightweight portable chiptune player for Windows x86, developed using Pascal (Delphi 7).

preview: https://www.youtube.com/watch?v=54Gu4KN6DnA

## Features

* Portable application
* No external DLL or framework required
* Approximately 200 KB
* Chiptune and music playback
* Export and conversion support

## Supported Formats

### Playback

* TXT — Arkos Tracker Text Format V1.0
* YM — Yamaha Music
* MID — MIDI
* MOD — ProTracker Module
* NSF — Nintendo Sound Format
* SID — Sound Interface Device

### Export / Conversion

* TXT — Arkos Tracker Text Format V1.0
* YM — Yamaha Music
* WAV — Waveform Audio Format

## System Requirements

* Windows x86
* No installation required

## Version History

### v0.0.1 – v1.1.12 — Initial Development

* Arx-Play originally started as a simple player for Arkos Project (`.aks`) files.
* Development focused on Arkos Project playback and MIDI mapping.
* Various problems were encountered during MIDI mapping.
* The project underwent significant changes to improve playback and conversion functionality.
* These changes eventually led to the development of a multi-format chiptune player.

### v1.1.13 – v1.1.15 — Arkos Tracker Text Format

* Changed the primary Arkos format from Arkos Project (`.aks`) to Arkos Tracker Text Format V1.0 (`.txt`).
* Added playback support for Yamaha Music (`.ym`).
* Added WAV (`.wav`) export.
* Updated and improved the player skin.

### v1.1.16 – v1.1.21 — Multi-Format Support

* Added MIDI (`.mid`) playback.
* Added export/conversion from MIDI to Yamaha Music (`.ym`).
* Added export/conversion to Arkos Tracker Text Format V1.0 (`.txt`).
* Added ProTracker Module (`.mod`) playback.
* Added Nintendo Sound Format (`.nsf`) playback.
* Added Sound Interface Device (`.sid`) playback.
* Expanded Arx-Play from a primarily Arkos-based player into a multi-format chiptune player.

### v1.1.22 – v1.1.23 — MIDI Export Improvements

* Fixed issues in MIDI-to-Text export.
* Improved the MIDI conversion process.
* Refined the resulting Arkos Tracker Text Format V1.0 output.

### Current Version

### Project Summary

Arx-Play began as a simple Arkos Project (`.aks`) player and gradually evolved into a lightweight, portable multi-format chiptune player. The project expanded through several development stages, adding support for Arkos Tracker Text Format V1.0, Yamaha Music, MIDI, ProTracker Module, NSF, and SID, along with WAV export and conversion capabilities.

The application is designed for Windows x86 and is developed using Pascal with Delphi 7. Arx-Play is portable, requires no installation, and operates without external DLLs or third-party frameworks. Its executable size is approximately 200 KB.
