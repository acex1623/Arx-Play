# Arx-Play

A lightweight portable chiptune player for Windows x86, developed using Pascal (Delphi 7).

## Features

* Portable application
* No external DLL or framework required
* Approximately 200 KB
* Chiptune and music playback
* Export and conversion support

## Supported Formats

### Playback

* TXT — Arkos Tracker Text Format V1.0
* YM — Yamaha Music
* MID — MIDI
* MOD — ProTracker Module
* NSF — Nintendo Sound Format
* SID — Sound Interface Device

### Export / Conversion

* TXT — Arkos Tracker Text Format V1.0
* YM — Yamaha Music
* WAV — Waveform Audio Format

## System Requirements

* Windows x86
* No installation required
